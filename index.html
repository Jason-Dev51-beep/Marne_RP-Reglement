Bienvenue dans le Code civil

Le présent Code civil constitue le règlement général de la communauté MARNE RP. Il encadre les interactions entre les joueurs, les activités de roleplay, les métiers, l'utilisation des équipements, les zones protégées ainsi que les activités légales et illégales fictives. Chaque membre est tenu de prendre connaissance des dispositions applicables et de respecter les autres participants. Ce document ne remplace ni les lois françaises, ni les conditions d'utilisation de Roblox, ni les règles officielles de Discord.

Comment utiliser ce document ?
